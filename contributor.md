# Installation guide

## Clone the project :

  ```bash
  $ git clone https://github.com/1pizzateam/GroovR.js.git
  ```

## Launch with docker

  ```bash
  $ cd GroovR.js/
  $ docker-compose up -d
  ```

  That builds the library (`groovr`).

OR

## Install project dependencies :

  ```bash
  $ cd GroovR.js/
  $ npm i
  ```

# Workflow

1. Create a branch
2. Make your changes
3. Build and test the library
4. Sync your branch with main
5. Commit your work
6. Push your branch and open a pull request against main

## Folders

- scripts/
- dist/
- src/
- tests/
